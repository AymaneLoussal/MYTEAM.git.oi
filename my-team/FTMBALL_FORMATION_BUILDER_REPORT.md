# Formation Builder implementation report

## Changes
Modified `resources/views/formations/create.blade.php`, `resources/css/app.css`, and `vite.config.js`. Added `resources/js/formation-builder.js`. The existing edit route reuses the builder view. The editor includes a charcoal toolbar, striped pitch, searchable roster, role-colored markers, selected-player controls, reset confirmation, and unsaved-change warnings. Raw coordinate inputs have been removed.

## Interaction and compatibility
Pointer capture supports mouse and touch dragging. Percent coordinates are clamped and submitted as the existing JSON positions array. Arrow keys move a focused marker; Shift increases the step. Player names are inserted using textContent. No shirt numbers are invented. Existing Laravel authorization, roster validation, distinct-player checks, coordinate bounds and role validation remain in place. No database changes were made.

Four presets provide eleven slots including goalkeeper. Applying a preset with assigned players requests confirmation and rearranges players in their existing array order. Preset choice itself is not stored; saved coordinates and roles are stored. Existing legacy roles remain supported. Reset restores the state loaded into the editor. Native form submission preserves Laravel validation feedback and old input.

## Verification
Vite production build, Blade compilation, route listing and audit passed (20 tests, 55 assertions). Full application test result is recorded in the task response. Existing backend formation regression tests were reused; new frontend automation and additional tests were not added.

## Starting XI and substitutes correction

Updated FormationController validation, the editor JavaScript, create/show Blade views and scoped CSS. Added FormationSquadTest. The existing positions JSON now optionally carries `status: starter|substitute`; tactical role remains GK/DEF/MID/FWD. Legacy entries without status infer starter, except legacy role `substitute`, which is interpreted as bench membership. Legacy status-like roles are displayed as MID because no tactical role was previously stored. Existing records are not rewritten. The server rejects more than eleven starters, duplicate IDs across the squad, invalid membership/status/coordinates/roles. No bench-size rule existed, so substitutes are limited by the eligible roster and unique assignment.

Add now prepares placement rather than assigning coordinates. Empty slots are clickable, direct list-to-pitch and bench dragging uses pointer capture, and a ghost marker previews placement. Bench and pitch moves derive status. Selected-player controls separate tactical role and status. Read-only views exclude bench players from the pitch and list them separately. Presets rearrange starters only after confirmation; bench players are retained. Cancellation restores the preset selector.

## Specific tactical positions and persistent presets

Added `config/tactics.php` as the shared server/frontend catalog with the four requested exact positional layouts, including LCDM/RCDM and independent slots for repeated ST labels. Added nullable `formations.preset` through migration `2026_11_15_020000_add_formation_preset`. Existing records are preserved. Before migration SQLite was backed up to `database/before-tactics-20261115-174955.sqlite` and integrity checked successfully.

The positions JSON now stores `position` (specific tactical assignment), `role` (broad group), `status`, `slot`, x/y and player_id. Updated Formation model, controller, create view and editor JS. Presets are restored after reload. New-format payloads require valid matching position/role, status and unique starter slot IDs. Old payloads and saved records remain supported. Legacy coordinates are retained, missing slots are assigned deterministically, and old broad roles receive default tactical labels. No user attributes or match-specific lineups are changed.

Clicking an occupied marker in placement mode or dropping on it supports confirmed starter swaps and substitute replacement. Replaced starters move to the bench. Free-space dragging adjusts existing starters without changing their slot. Available players must be placed into a tactical slot. Specific-position edits customize that slot's assignment and derive its broad role. Reset position returns to the preset slot coordinates. Preset changes request confirmation and preserve every player and substitute, assigning starters in their existing order.
